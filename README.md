# Practice OOP in C#

A mini-project in C# demonstrating the use of classes, inheritance, and constructor chaining

## Completed tasks: 
* **Working with classes:** A base class `Person` has been created, featuring `Name` and `Age` properties, as well as a `Print()` method for displaying information.
* **Inheritance:** A `Student` subclass (inheriting from `Person`) has been implemented, featuring additional fields—`Group` and `AverageMark`—a `PrintInfo()` method, and functionality to filter a list of students based on age and average grade.
* **Class constructors:** An `Employee` class (inheriting from `Person`) has been created with `Salary` and `WorkExperience` properties; constructor overloading has been implemented using the `this` keyword.

## Project structure
* `Program.cs`— the program entry point, creation of object arrays, and verification of method functionality.
* `Person.cs` — a description of the base human class.
* `Student.cs` — a description of the student class.
* `Employee.cs` — — a description of the employee class.
